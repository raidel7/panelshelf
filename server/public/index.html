Data safety Backup and restore

Save sources, reading orders, metadata matches, manual edits, progress, shelf status, and chronology preferences in one portable JSON file. Comic archives and provider credentials are never included.

Getting help Support bundle

Versions, source folders, counts, and the end of the server log, in one file to attach to a bug report. No device tokens, no provider keys, and nothing about what anyone has read. Source folder paths are included, so read it before posting it.

Housekeeping Library review

Copies of the same comic, and online matches that were too close to call. Nothing here changes anything on its own.

Covers Cover cache

Covers are built the first time a shelf draws them. Caching them in one pass does that work now instead of a card at a time.

Readers Reader profiles

One library, one household — and a shelf each. A reader profile keeps two people's reading positions and hidden chronology branches apart. It is not an account: it has no password and grants no access.
